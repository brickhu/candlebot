# Aggr.trade 示例图片目录

## 目录结构
```
ai/examples/aggr/
├── example_1.jpg/png      # 示例图片1
├── example_2.jpg/png      # 示例图片2
├── metadata.json          # 示例图片元数据
└── README.md              # 本文件
```

## 示例图片要求
1. **格式**：JPG、PNG或WebP
2. **大小**：不超过5MB
3. **分辨率**：建议宽度800-1200px
4. **内容**：清晰的aggr.trade截图，包含完整指标

## 如何添加新示例
1. 将图片放入此目录
2. 更新 `metadata.json` 文件
3. 在平台配置中更新示例列表

## 示例图片命名规范
- `example_{编号}_{描述}.{扩展名}`
- 例如：`example_1_uptrend.jpg`, `example_2_downtrend.png`

## 使用方式
系统会在分析时参考这些示例图片，帮助AI更好地理解图表结构和指标含义。
