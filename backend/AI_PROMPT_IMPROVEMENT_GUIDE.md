# AI Prompt 改进指南

## 问题诊断

### 1. 数据指标不准的原因
- **指标定义模糊**：如"密集色带"、"上升/下降"没有量化标准
- **缺乏阈值**：没有明确的数值判断标准
- **主观评级**：概率计算缺乏客观依据
- **输出不一致**：AI理解偏差导致结果波动

### 2. 示范图片配置缺失
- 系统没有示例图片参考机制
- AI缺乏学习样本，分析质量不稳定
- 无法确保分析格式统一

## 解决方案实施

### 1. 量化指标定义 ✅ 已完成

**改进内容：**
- 为每个指标添加具体量化标准
- 定义明确的阈值和判断条件
- 统一概率计算规则

**关键量化点：**
- **趋势判断**：连续3根以上阳线/阴线
- **CVD角度**：>15度为上升，<-15度为下降
- **Delta连续性**：连续3根以上同向
- **成交量**：>1.5倍平均为放量，<0.7倍为缩量
- **概率计算**：基础50% + 信号调整 ± 共振调整

### 2. 示例图片系统 ✅ 已完成

**系统架构：**
```
ai/examples/aggr/
├── example_1_uptrend.jpg    # 示例图片
├── example_2_downtrend.png  # 示例图片
├── metadata.json           # 元数据配置
└── README.md              # 说明文档
```

**配置方式：**
1. 在平台配置中启用示例图片
2. 配置示例图片目录和格式
3. 定义示例图片的元数据和预期分析结果

### 3. 结合示例的输出格式 ✅ 已完成

**重大改进：将示例直接集成到输出格式中**

**功能特点：**
- **一体化设计**：示例和输出格式在同一文件中
- **完整参考**：提供2个完整的分析示例（上升/下降趋势）
- **具体数值**：包含价格、角度、百分比等具体数值
- **格式示范**：展示正确的Markdown表格和元数据格式
- **用户模板**：清晰的空白模板供AI填充

**示例包含：**
1. **ETHUSD 15分钟上升趋势示例**
   - 完整的技术面信号表格
   - 具体的概率预测场景
   - 详细的总结和操作建议
   - 完整的元数据格式

2. **BTCUSD 1小时下降趋势示例**
   - 不同的市场场景
   - 反向的技术信号
   - 风险提示和止损建议

## 监控与优化

### 1. 监控指标
- **分析准确性**：与实际行情对比
- **响应一致性**：相同图片多次分析结果
- **格式合规性**：输出是否符合指定格式
- **元数据完整性**：所有必需字段是否齐全

### 2. 优化建议

**如果指标仍然不准：**
1. **调整量化阈值**：修改角度、连续根数等参数
2. **增加更多示例**：在输出格式中添加更多场景示例
3. **细化概率计算**：调整权重分配
4. **添加验证规则**：增加输出格式检查

**如果输出格式不一致：**
1. **强化示例**：在输出格式中添加更详细的示例
2. **简化模板**：让用户模板更清晰明确
3. **添加格式检查**：在prompt中强调格式要求
4. **测试不同图片**：确保格式在各种情况下都一致

## 故障排除

### 常见问题

1. **输出格式未更新**
   - 检查 `output_format` 文件是否已修改
   - 确认配置管理器缓存（可调用 `/debug/ai-config` 端点）
   - 重启服务清除缓存

2. **量化指标无效**
   - 确认平台prompt文件已更新
   - 检查组合提示词是否正确加载
   - 重启服务清除缓存

3. **输出格式不一致**
   - 检查AI是否遵循示例格式
   - 验证元数据解析正则表达式
   - 测试不同图片的分析结果

4. **提示词过长**
   - 当前提示词约4000-6000字符
   - 如遇API限制可简化示例
   - 确保关键部分（量化指标、示例、模板）保留
